# 人生の知恵の本棚

父から子へ、人生で本当に大切な知恵を残していく学びの図書館サイトです。

## ファイル構成

```
chie-no-hondana/
├── index.html              トップページ
├── about.html              この図書館について
├── letter.html             父からテルへ
├── lessons/
│   └── time-investment.html   教材詳細ページ(時間の使い方)
└── assets/
    ├── css/style.css       デザイン(色・大きさ)
    ├── js/main.js          動き(PDFチェックなど)
    ├── pdf/                教材PDFを置く場所
    └── images/             画像を置く場所
```

## 公開方法

Cloudflare Pages を使って公開しています。
GitHubに変更を反映すると、自動でサイトが更新されます。
